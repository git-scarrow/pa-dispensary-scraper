# Inspirations / Credits

This project's MCP server implementation (`mcp_server.py`) is informed by:

- `modelcontextprotocol/python-sdk` (MIT): `FastMCP` server patterns, decorators for tools/resources, and stdio/HTTP transports.
- `modelcontextprotocol/servers` (MIT): naming and packaging patterns for practical MCP servers that expose local data + action tools.

These sources were used as architectural references and adapted to this project's Python adapter modules and PA store registry layout.
